# FastКонспект

Веб-сервис, который превращает загруженный документ (PDF, DOCX, TXT) в конспект с выбранными объёмом и структурой и отдаёт его в PDF.

Учебный проект по МДК.01.13 «Управление программными проектами».

## Что умеет (MVP)

- Регистрация и вход по email и паролю
- Загрузка документа (.pdf, .docx, .txt) или вставка текста вручную
- Выбор объёма конспекта: краткий, средний, подробный
- Выбор структуры: список тезисов или конспект по блокам
- Генерация конспекта локальной языковой моделью
- Просмотр и правка результата (Markdown: заголовки, списки, жирный, курсив)
- Сохранение, редактирование и удаление конспектов
- Экспорт в PDF

**Цель:** конспект документа до 20 страниц менее чем за минуту.

**Не входит в этот семестр:** аудио, видео, фото и изображения, распознавание речи, совместное редактирование в реальном времени.

## Стек

| Часть | Технология |
|---|---|
| Интерфейс | Jinja2 + HTMX |
| Бэкенд | Python, FastAPI, Pydantic |
| Извлечение текста | PyMuPDF, python-docx |
| Языковая модель | gemma3:4b через Ollama (запасной вариант: qwen2.5:3b) |
| База данных | PostgreSQL, SQLAlchemy |
| Экспорт в PDF | WeasyPrint |
| Запуск | Docker Compose (приложение и БД), Ollama на компьютере |

## Проверка модели

Проверка выполнена на тестовом компьютере: AMD Ryzen 5 5600, 16 ГБ ОЗУ, GeForce RTX 3050 6 ГБ, Windows 11.

| Параметр | Значение |
|---|---|
| Модель | gemma3:4b через Ollama (около 3 ГБ) |
| Окно контекста | 32768 токенов, 100% на видеокарте |
| Размер входа | 14 094 токена (около 16–18 страниц) |
| Размер конспекта | 947 токенов |
| Чтение документа | 7,7 с |
| Генерация конспекта | 25,8 с (около 37 токенов/с) |
| Всего | 37,8 с |

Вывод: документ до 20 страниц обрабатывается менее чем за минуту в режимах «краткий» и «средний». Режим «подробный» нужно проверить отдельно.

## Запуск
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload

Открыть: http://127.0.0.1:8000

## Как работаем с Git

- В `main` напрямую не пушим.
- У каждого своя ветка (например, `dasha-frontend`), изменения попадают в `main` через Pull Request; сливает Ксения.
- Каждый правит только файлы своей зоны (см. таблицу «Команда»).
- Пароли, ключи и файл `.env` в репозиторий не попадают (они в `.gitignore`).
- Названия коммитов короткие и по делу: «Добавила страницу загрузки».
